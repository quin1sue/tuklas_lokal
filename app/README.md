# Tuklas Lokal — Flutter app

Android-first Flutter client for Tuklas Lokal. This directory contains the mobile app only;
project scope, architecture, and setup notes live at the repository root.

- Product and MVP scope: [`../docs/MVP.md`](../docs/MVP.md)
- Architecture: [`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md)
- Setup and verified tool versions: [`../docs/PROJECT_SETUP.md`](../docs/PROJECT_SETUP.md)

## Common commands

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

The app currently contains the unmodified Flutter counter scaffold. The real app shell
arrives in the Phase 1 vertical slice; see [`../docs/ROADMAP.md`](../docs/ROADMAP.md).
